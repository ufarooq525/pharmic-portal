# Pharmic LH portal: security, UX and QA audit (12 Nov 2026)

Run against the Laragon copy (`http://localhost/pharmic-portal/public`) with the real October 2026
distributor PDFs, the owner account and three temporary test users (viewer, data entry limited to
Hamdan, medical rep). Code review covered every controller, action, request, repository, route
file, middleware and Blade view.

## Checked and passing

**Security**
- Every web route needs a login, and every write route checks the role from the approved permissions matrix. A viewer gets 403 on confirm, payment, stock receipt, invoices, payroll, users and activity log.
- Distributor scope: a data-entry user limited to Hamdan gets 403 on Irfan's import and does not see other distributors in lists.
- Medical rep: lands on My territory. Their own payslip opens; another rep's returns 403, and so do Imports, Users and Invoices.
- Login is throttled (10 a minute). Passwords need at least 10 characters. Wrong password: no session.
- No raw SQL with user input; `pdftotext` is called with an argument list (no shell); the only unescaped Blade output is fixed SVG icons; JavaScript writes text with `textContent`.
- Uploads accept PDF only, up to 10 MB, stored privately under a random name. A text file posing as a PDF and a broken PDF are both refused.
- Mass assignment: every write goes through a FormRequest and an Action with validated fields only.
- Every create, change, confirm, revert, payment, receipt and user change is in the append-only Activity log.

## Before going live (production checklist)

- Point the web server's document root at `public/` (the root `.htaccess` is only a safety net).
- In `.env`, set:
  - `APP_ENV=production`
  - `APP_DEBUG=false`
  - `SESSION_SECURE_COOKIE=true` (once on HTTPS)
  - a strong database password
  - `COMPANY_NTN`, `COMPANY_STRN`, address and phone for invoices
- Change the owner password at first sign-in (the red reminder enforces this visually).
- Run `php artisan optimize` after each deploy, and `php artisan test` before it.
- Back up the database and `storage/app/private` (the uploaded PDFs) daily.
